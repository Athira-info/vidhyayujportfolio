# YUJ – Yoga & Wellness Portfolio

A responsive yoga and wellness portfolio website designed to showcase yoga practices, services, experience, and holistic wellness offerings through a clean and elegant interface.

## 🌿 About the Project

YUJ is a yoga portfolio website created to present a yoga instructor's professional journey, qualifications, teaching experience, and wellness services.

The website focuses on a peaceful visual experience with a nature-inspired aesthetic, soft colour palette, smooth animations, and a user-friendly layout.

## ✨ Features

- Fully responsive design for desktop, tablet, and mobile devices
- Elegant landing page with custom branding
- About section introducing the yoga instructor
- Yoga sessions and wellness services
- Image gallery to showcase yoga practices
- Qualifications and professional experience
- Contact section for session enquiries
- Smooth scrolling and scroll animations
- Interactive navigation and hover effects

## 🎨 Design & Technologies

**Frontend:**
- HTML5
- CSS3
- JavaScript

**Libraries & Tools:**
- Bootstrap
- AOS (Animate On Scroll)
- Google Fonts
- Font Awesome

**Design Approach:**
- Minimal and nature-inspired interface
- Soft beige, sage, and earthy colour palette
- Typography pairing with Playfair Display and DM Sans
- Responsive layouts and subtle animations

## 📱 Responsive Design

The website is designed to provide a consistent browsing experience across different screen sizes, including desktops, tablets, and smartphones.
